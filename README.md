# Каталог

Небольшой каталог товаров: страница на Next.js, API на FastAPI, бот на aiogram 3. Картинки лежат в MinIO, записи о товарах — в PostgreSQL.

Страница открывается в браузере и как Telegram Mini App. Заголовок страницы — «Каталог», под ним список товаров.

## Запуск

```bash
cp .env.example .env
```

В `.env` заполнить:

- `BOT_TOKEN` — токен от BotFather
- `ADMIN_IDS` — telegram id администраторов через запятую
- `WEBAPP_URL` — публичный https-адрес, по которому Telegram откроет каталог
- `INTERNAL_TOKEN` — общий секрет бота и API

```bash
docker compose up -d --build
```

Каталог: http://localhost:3000

Консоль MinIO: http://localhost:9001 (логин и пароль — `S3_ACCESS_KEY` / `S3_SECRET_KEY`).

## Как пользоваться ботом

На `/start` и на обычное сообщение бот отвечает «У меня есть товар» и даёт кнопку «Каталог». Та же кнопка стоит в меню чата. Обе открывают Mini App.

Администратор добавляет товар командой `/create` (в списке команд она называется «Создать товар») и затем одним сообщением: фотография, в подписи — название. Бот кладёт файл в MinIO и строку в PostgreSQL.

Чужой пользователь с фотографией каталог пополнить не может.

## Отказоустойчивость

Состояние сервиса только в PostgreSQL и MinIO. У API, страницы и бота нет сессий и файлов на диске контейнера, поэтому реплики взаимозаменяемы:

```bash
docker compose up -d --scale backend=2 --scale frontend=2 --scale bot=2
```

Порты наружу публикует только nginx. Имя `frontend` резолвится через DNS Docker, nginx не держит список реплик в конфиге.

Бот тоже можно поднять в нескольких копиях. Long polling у Telegram один на токен, поэтому реплика берёт advisory lock в Postgres и только она вызывает `getUpdates`. Если процесс умирает, соединение закрывается, лок отпускается, его забирает другая реплика. Обработчики при этом ничего не помнят: товар создаётся одним сообщением, отдельного сценария с шагами нет.

`GET /api/products` не кэшируется на фронте (`no-store`), у каждой реплики один и тот же список из базы.

## Схема

```
браузер / Telegram Mini App
        |
      nginx :3000
        |
   frontend (Next.js)   можно несколько
        |
   backend  (FastAPI)   можно несколько
      |            |
  postgres        minio

bot (aiogram)  --->  backend
   один держит polling, остальные ждут лок
```
